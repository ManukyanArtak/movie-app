# Movie Explorer

A modern movie discovery app built with React, TypeScript, and the TMDb API.

## Features

- Browse popular movies with infinite scroll
- Search movies by title
- Filter by genre
- View movie details, cast, and trailers
- Save favorites to localStorage
- Responsive design

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. (Optional) Create `.env.local` with your TMDb Access Token:

```
VITE_TMDB_ACCESS_TOKEN=your_token_here
```

3. Start the development server:

```bash
npm run dev
```

4. Open `http://localhost:5173` in your browser

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run test` - Run tests
- `npm run test:coverage` - Run tests with coverage
- `npm run lint` - Run ESLint

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router 7
- TMDb API
